# Feste Burg?

Wenn es brenzlig wird, ziehen wir uns gerne in die Sicherheit zurück: Mauern, Grenzen, Zäune. Jesus ruft uns zur Nachfolge und stellt dabei gerade nicht Sicherheit in Aussicht, sondern weites Land und echtes Leben. Das ist riskant, aber wer wagt, ihm nachzufolgen, gewinnt mehr, als man sich vorstellen kann.
